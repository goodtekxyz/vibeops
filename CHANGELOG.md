# Changelog

All notable changes to VibeOps are documented here.

## 0.1.0 - 2026-05-11

Initial MVP release candidate.

- MVP 1 Project Bootstrapper: `vibeops init`, `vibeops status`, template install, Cursor rules, AGENTS.md, agents/prompts/workflows, project docs, TASK template.
- MVP 2 Planner: interactive `vibeops plan`, ProjectBrief output, Cursor planning prompt, `vibeops task generate` prompt/scaffold modes.
- MVP 3 Git Task Lifecycle: `task start`, `task prompt`, `task check`, `task done`, `task rollback` with dry-run/read-only defaults and explicit rollback confirmation.
- MVP 4 Notion Dashboard Sync: `notion init`, `notion test`, `notion sync`, `task pull`, data_source-first discovery/resolution, schema/status-option validation, metadata-only sync, and local TASK skeleton pull.
- Packaging polish: npm package metadata, MIT license, smoke checks, publish dry-run workflow, and README command reference.
