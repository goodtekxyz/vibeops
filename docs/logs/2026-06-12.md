# 2026-06-12

- Made `vibeops task ship` state-aware. It now detects the TASK's PR/MR state via a single source (`resolveTaskMergeRequestLifecycle`) and branches:
  - **none + In Progress** → first submit (push + new PR, Status → Shipped).
  - **open** → commit + push the same branch to update the existing PR (no new PR); CI re-runs.
  - **merged** → new PR cycle (former `reship`), guarded by an interactive confirm or `--new-cycle` in non-interactive mode.
  - **none + Shipped** → mismatch hint (likely merged + synced).
- Added flags `-m/--message`, `--new-cycle` (alias `--reship`), `--no-commit`, `--non-interactive`. Commit messages are TASK-id-scoped (`feat(task-001): …`).
- Extracted reship body into `src/lib/task-new-cycle.ts` (`runPostMergeNewCycle`); `task reship` is now a deprecated alias that delegates to `ship --new-cycle`.
- New files: `src/lib/task-ship-state.ts`, `src/lib/task-commit-msg.ts`, `src/lib/task-new-cycle.ts`. Updated: `src/commands/task-ship.ts`, `src/commands/task-reship.ts`, `src/cli.ts`, `src/lib/pr-create.ts`, `src/lib/task-effective-status.ts`, `src/lib/task-git-commit.ts`, `src/lib/resolve-task.ts`, `src/lib/inquirer-helpers.ts`.
- Docs: README, CHANGELOG (Unreleased), `05-current-state.md`, and AGENTS/CLAUDE/cursor-rule templates updated.
- Tests: added `tests/ship-state.test.mjs` (node:test) for state mapping, TASK-id scoped messages, and PR-number parsing; extended `scripts/smoke.mjs`.
